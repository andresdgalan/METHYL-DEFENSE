In these analyses we evaluate how much epigenetic variability is explained by the herbivory treatments and their interaction. We analysed overall epigenetic variability and separately for each context. We used the methylation percent of each SMP (4531 in CpG, 3738 in CHH, 3738 in CHH) to construct an euclidean epigenetic distance matrix between samples (40) using cluster::daisy.

We conducted dbRDA using vegan::capscale with the epigenetic distance matrix as response and the herbivory treatments as predictors. To account for genetic variability, we summarized the SNP data (5501 SNPs) into principal components using PCA, and included the first PC (that explains 23.57% of the genetic variability) as a condition in a constrained dbRDA. We tested the significance of the model using a permutation test with 9999 permutations and obtained adjusted R2 values using the function RsquareAdj from the vegan package. We visualized the structure of the data in a 2-D space using the constrained ordination axes (RDA axes). We ran the following models for all contexts together and separately for each sequence context:

  1. Epigenetic distance ~ Maternal herbivory

  2. Epigenetic distance ~ Maternal herbivory * Real-time herbivory

  3. Epigenetic distance ~ Maternal herbivory * Real-time herbivory + Condition (PC)

  4. Epigenetic distance ~ PC
